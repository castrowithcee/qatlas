# `--ask` in run

The user is reachable during the run and decides. Whatever project knowledge does not settle and would
otherwise become an assumption or a human handoff, you present as a card by [presenting
decisions](../../references/playbook-decision-card.md) at the moment it arises, wait for the answer and record
it at the task as that file prescribes. You never assume in the user's place. Only what the user cannot
settle in the chat, such as an external prerequisite or an action only they can take, becomes a human handoff
to `review`.
