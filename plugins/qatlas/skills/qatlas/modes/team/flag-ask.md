# `--ask` in team

The user is reachable during the run and decides. A `question` of a lead or the integrator that project
knowledge does not settle you present to the user as a card by [presenting
decisions](../../references/playbook-decision-card.md), wait for the answer and pass it on with `answer`.
You never assume in the user's place. The flag changes only your own channel: the leads receive `--ask` in
every case, because their user is you.
