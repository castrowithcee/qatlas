# Bring the knowledge space onto the fixed layout

`.qatlas-project/` now has fixed folders, each holding only its types; only tasks keep an ID in their name,
every other content file is named `<type>-<slug>.md`. Plans became their own type, decisions change in
place with a new `version`, and `history`, archives of superseded decisions and a `FRAMEWORK.md` inside the
knowledge space no longer exist there.

- Check whether the knowledge space already matches the layout of `qatlas-core-filing`. If it does, nothing
  needs to change in the project.
- Otherwise migrate the knowledge space as part of this update; its mapping goes into the update's approval
  before anything changes, and it points every reference in the repo, such as project instructions, to the
  new paths.
- Missing fixed folders alone may be created right away, empty ones with `.gitkeep`.
